# Tabela HTML - Notas de Alunos

Este projeto contém um exercício básico de HTML que cria uma tabela
com notas de alunos.

## Descrição
A tabela apresenta o nome do aluno, a tecnologia estudada e a nota
correspondente. O objetivo é praticar a criação de tabelas utilizando
as tags:
- `<table>` 
- `<tr>` 
- `<td>` 
- `<h2>` para título

## Conteúdo da tabela
- Ronaldo — HTML — Nota 9  
- Mazei — Javascript — Nota 10  

## Objetivo do exercício
Fixar a estrutura básica de uma tabela em HTML e organizar dados
em linhas e colunas.
